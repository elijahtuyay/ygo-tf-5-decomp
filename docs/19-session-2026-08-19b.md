## The finding that mattered: mine idioms, not functions

The automated pipeline had already swept every module, so re-running it produced
almost nothing — `rel_story` yielded zero new functions from a full pass and
`rel_field` yielded three. Its ceiling on already-swept modules is reached.

What worked instead was to stop looking at functions and start looking at
**shapes**. Reduce every unmatched function to its sequence of mnemonics with
all operands discarded, and count how many functions share each sequence:

    126 shape families with >=3 unmatched members, covering 562 functions

Compiler-generated code repeats verbatim, so solving one shape by hand and then
extracting the per-instance operands from the disassembly matches the whole
family mechanically. That produced **104 functions**, most without decompiling
anything:

| family | members | what it is |
|---|---:|---|
| struct copy | 32 | `*dst = *src` inlined as a counted loop |
| spawn-and-set | 43 | create an object, set one field if it succeeded |
| seh-dispatch | 25 | conditionally transform a short, then tail-call |
| adapted twins | 4 | leftovers from the shape-twin tier |

`scripts/struct_copies.py` is the reusable form; the technique itself is written
up in `docs/11`.

### A new compiler lever

Solving seh-dispatch turned up something worth its own entry: **a K&R
declaration forces sign-extension at the call site, a prototype suppresses it.**
One function needed both forms in the same file — K&R on the first callee to
produce `seh $a0, $a0`, a prototype on the second to avoid a third `seh`.
Getting it wrong looks like a one-word size mismatch, which reads as a
scheduling problem and is easy to misdiagnose.

## The hybrid build now completes 17 modules

Two bugs fixed since it first worked:

1. **It split the raw disassembly** rather than the prepared one, so every
   module containing Allegrex `min`/`max`/VFPU opcodes failed to assemble.
2. **It selected functions by "defined in `src/`" rather than "verified".** A
   function can sit in a source file and still not match — `src/rel_html_view.c`
   deliberately carries a non-matching `func_00000470`. Selecting on the
   verified baseline instead carries such functions as assembly, which is what
   makes those modules completable at all. Fixing this exposed a second bug:
   filtering before computing function boundaries made the excluded body get
   swallowed into the preceding function and compiled anyway. Boundaries must
   come from every definition; filtering happens only at emit time.

## Smaller results

- **The differ resolves baked addresses from the symbol name.** splat names an
  unnamed global after the address it occupies, so `D_00B2EE90` *is*
  `0x00B2EE90`; the Makefile already relies on this to `PROVIDE()` them to the
  linker. The differ previously knew only 8 such addresses from a hardcoded
  table. This is not a loosening — the computed immediate is still compared.
- **`auto_decomp` now reads field widths and callee arity from the target**
  rather than guessing. The width of an unknown struct field is stated by the
  load opcode at that offset; callee arity comes from `scripts/gen_context.py`,
  which measures it by read-before-write plus tail-call propagation. m2c only
  reliably sees `$a0-$a3`, so arguments five to eight — and anything a tail-call
  trampoline passes through — were being dropped, producing drafts that compile
  to too FEW instructions. This measurably reduced size mismatches, though it
  converts to matches less often than hoped.
- **`include/ehsys.h`** carries prototypes for the 985 engine functions the
  modules actually call.

## Dead ends confirmed (do not re-try without new evidence)

- **Branch-likely selection.** A loop where the target has `bnez` plus `nop` and
  we emit `bnezl`. No loop shape, optimisation level or `#pragma
  optimization_level` moved it.
- **`byte = (byte & ~1) | (arg & 1)` operand order.** Three phrasings tried.
- **Commutative `addu` operand order** in an indexed address computation
  (`base + index*n` versus `index*n + base`). Four phrasings tried, all one word
  from matching.
